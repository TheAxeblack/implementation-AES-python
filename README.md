# implementation-AES-python

Ce repository contient une implémentation de l'algorithme de chiffrement AES (Advanced Encryption Standard) sur 128 bits en Python.

## Prérequis

- Python 3.12

## Installation

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/TheAxeblack/implementation-AES-python.git
   ```

2. Accédez au répertoire du projet :

   ```bash
   cd implementation-AES-python
    ```

3. Exécutez le script Python :

   ```bash
   python3 main.py
   ```

_PS: Si vous voulez d'avantage de logs, il est nécessaire d'aller décommenter les lignes correspondantes dans le fichier `main.py`._
